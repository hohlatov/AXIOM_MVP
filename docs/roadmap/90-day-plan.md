# Фаза 27 — Исполняемый 90-дневный план AXIOM

Статус: АУДИТ / ПРЕДЛОЖЕНИЕ. Конкретизирует этапы NOW и MVP из `docs/roadmap/product-roadmap-v2.md` в исполняемые задачи. Команда, как задано вводными: **PM**, **Backend-focused Full-Stack**, **Data Scientist/ML Engineer**. Ролей отдельного фронтенд-разработчика, дизайнера и content-эксперта в команде нет по вводным данным — это явное организационное ограничение, отмеченное ниже там, где оно создаёт риск.

Формат: Задача / Приоритет / Роль / Зависимости / Ожидаемый результат / KPI.

## Организационные риски плана (честно, не завышая уверенность)

- В команде нет отдельной дизайнерской роли — онбординг и любые UI-доработки в этом плане реализуются силами PM и Full-Stack без профессионального UX/UI-дизайна; это осознанный компромисс ради скорости, а не признак того, что дизайн не важен (см. `docs/product/02-ux-ui-audit.md`).
- В команде нет отдельной content-роли для предметного наполнения (геометрия, русский язык) — задачи по контенту выше распределены на PM, что может быть узким местом при объёме работы, необходимом для полноценного покрытия кодификатора (см. `oge-knowledge-graph.md`); если PM не обладает предметной экспертизой по математике/русскому языку на уровне ОГЭ, потребуется либо привлечение внешнего эксперта, либо пересмотр темпа наполнения банка — это открытый вопрос, не решённый в рамках аудита.
- Доступ к GPU для замера latency ИИ-сервиса (задача дней 1–30) не подтверждён как имеющийся ресурс — если недоступен, задача блокируется, и весь ИИ-трек (Explain-my-mistake, дни 31–60) сдвигается.
